# Mobile Computing — Assignment 2 (CO2)

This folder is organised question-wise from the supplied assignment brief.

Each Q1–Q7 folder contains a runnable Python source file and output.svg, a terminal-style image capture made from that script's successfully executed console output. Install NumPy with pip install numpy, then run the .py file with Python 3.

The simulations use fixed random seeds and disclose their simplifying assumptions. They are teaching models, not field measurements or standards-conformance simulators. Q6 also documents a limitation in the supplied report: criterion weights are given, but criterion-by-technique ratings are not, so a valid weighted sensitivity score cannot be reproduced without additional inputs.

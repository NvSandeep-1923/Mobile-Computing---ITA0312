# Q5 – Proactive Routing Protocols in Mobile Networks

**Python demonstration:** `q5_dsdv_routing.py`

Implements a small DSDV-style routing-table update example. It accepts a route with a newer destination sequence number, uses hop count to choose a shorter route when sequence numbers match, and rejects older route information.

**Files:** Python source, captured console output, console-output image, and final route-table trace.

**Scope:** This is a small teaching model of the assignment's DSDV concepts, not a full protocol simulator.

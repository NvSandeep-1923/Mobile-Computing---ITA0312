# Mobile Computing – Assignment 3 (CO3)

Organized into seven question-specific folders. Each question contains a Python demonstration, its captured console output, and a console-output image (SVG). Supporting traces and CSV results are included where relevant.

The programs are instructional models built from the assignment scenarios. They are not packet-level physical-network measurements or full ns-3/OMNeT++ simulations; each question README notes the scope and assumptions.

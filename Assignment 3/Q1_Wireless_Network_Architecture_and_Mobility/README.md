# Q1 – Wireless Network Architecture and Mobility Analysis

**Runnable implementation:** `q1_wireless_mobility.py`

This discrete-event worked simulation models 20 transmitted packets under low, medium and high mobility. It reports packet delivery ratio, packet loss, and illustrative handoff delay.

**Files:** Python source, captured terminal output, rendered console-output image, and CSV results.

**Important:** The assignment states exact measurements depend on network speed, signal strength and handoff duration. These program values are illustrative assumptions, not physical measurements.

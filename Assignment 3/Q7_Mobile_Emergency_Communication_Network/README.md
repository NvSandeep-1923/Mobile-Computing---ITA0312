# Q7 – Design a Mobile Emergency Communication Network

**Runnable illustrative simulation:** `q7_emergency_network.py`

Models a small disaster-response ad hoc network. It performs breadth-first AODV-style on-demand route discovery from vehicles to a hospital gateway, then removes a link and searches for an alternate route.

**Files:** Python source, captured terminal output, rendered console-output image, and text trace.

**Important:** This is a graph-level illustrative demonstration, not a packet-level ns-3/OMNeT++ simulation. The assignment's example test configurations are proposed test cases, not measured results.
